نظام التفويج اللوجستي — Umrah Logistics Pro · آخر تحديث: 30 يوليو 2026

١. نظرة عامة

هذا النظام أداة داخلية تستخدمها شركات ومكاتب خدمة الحجاج والمعتمرين لتتبع رحلات التفويج اللوجستي (النقل، المواعيد، حالة الرحلات). تصف هذه السياسة البيانات التي نجمعها عبر تطبيق الويب وإضافة المتصفح المرافقة له، وكيفية استخدامها وحمايتها.

٢. البيانات التي نجمعها

  • بيانات الحساب: اسم المستخدم وكلمة المرور (مخزَّنة بصيغة مُشفّرة عبر bcrypt، ولا يمكن لأحد استرجاعها كنص واضح).
  • بيانات التفويج اللوجستي: ما يُدخله الموظف من بيانات الرحلات — اسم المجموعة، رقم الرحلة، التاريخ والوقت، نقطة الانطلاق والوجهة، الحالة، وأي ملاحظات مرفقة. قد تتضمن هذه البيانات أسماء المعتمرين إذا أدرجها الموظف ضمن نص التفويج.
  • إعدادات بوت تيليجرام (اختياري): إذا فعّل المستخدم إشعارات تيليجرام، يُخزَّن رمز البوت ومعرّف المحادثة الذي أدخله بنفسه لإرسال التنبيهات.
  • بيانات إضافة المتصفح (اختياري): عند استخدام إضافة "Umrah Logistics Capture"، تقرأ الإضافة نص الصفحة النشطة فقط عند نقر المستخدم على زر الالتقاط، أو تلقائيًا على صفحات بوابتَي نسك وحج الرسميتين، ثم ترسل هذا النص إلى حساب المستخدم على خادمنا.

٣. كيفية استخدام البيانات

تُستخدم البيانات حصريًا لتشغيل لوحة التفويج اللوجستي: عرض الرحلات وتحديثها، جدولة تنبيهات القرب من موعد الرحلة، وإرسال إشعارات تيليجرام التي يُفعّلها المستخدم بنفسه. لا تُستخدم البيانات لأي غرض تسويقي أو يخرج عن الغرض الأساسي للنظام.

٤. التخزين والمشاركة

تُخزَّن جميع البيانات في قاعدة بيانات خاصة بمشغّل النظام. لا تُباع أو تُشارَك بياناتك مع أي طرف ثالث، باستثناء إرسال محتوى الإشعار مباشرة إلى واجهة برمجة تطبيقات تيليجرام (Telegram Bot API) عند تفعيل هذه الميزة اختياريًا من قِبل المستخدم نفسه.

٥. الاحتفاظ بالبيانات وحذفها

تُحفظ بيانات حسابك طالما بقي نشطًا. لطلب حذف حسابك أو بياناتك، يُرجى التواصل معنا عبر البريد الإلكتروني أدناه.

٦. الأطفال

هذا النظام أداة عمل داخلية موجَّهة لموظفي شركات ومكاتب الخدمة، وغير موجَّه للأطفال.

٧. التغييرات على هذه السياسة

قد نحدّث هذه السياسة من وقت لآخر. سيظهر تاريخ آخر تحديث أعلى هذه الصفحة دائمًا.

Privacy Policy

Umrah Logistics Pro (Tafweej Logistics System) · Last updated: July 30, 2026

1. Overview

This system is an internal tool used by Umrah/Hajj service agencies and offices to track ground-transport logistics (trips, schedules, trip status). This policy describes the data collected through the web application and its companion browser extension, and how it is used and protected.

2. Data We Collect

  • Account data: username and password (stored hashed via bcrypt; never recoverable as plain text).
  • Logistics data: trip information staff enter — group name, flight number, date/time, origin/destination, status, and any attached notes. This may include pilgrim names if a staff member includes them in itinerary text.
  • Telegram bot settings (optional): if the user enables Telegram notifications, we store the bot token and chat ID the user provided to send their own alerts.
  • Browser extension data (optional): when using the "Umrah Logistics Capture" extension, it reads the active tab's text only when the user clicks the capture button, or automatically on the official Nusuk and Haj portal pages, and sends that text to the user's own account on our server.

3. How We Use Data

Data is used exclusively to operate the logistics dashboard: displaying and updating trips, scheduling proximity alerts, and sending Telegram notifications the user has chosen to enable. Data is never used for marketing or any purpose outside the system's core function.

4. Storage & Sharing

All data is stored in a database operated by the system owner. We do not sell or share your data with any third party, except for sending notification content directly to the Telegram Bot API when the user has voluntarily enabled that optional feature.

5. Data Retention & Deletion

Your account data is retained while your account remains active. To request deletion of your account or data, contact us at the email below.

6. Children

This system is an internal work tool for agency staff and is not directed at children.

7. Changes to This Policy

We may update this policy from time to time. The "last updated" date at the top of this page always reflects the latest version.

8. Contact Us
